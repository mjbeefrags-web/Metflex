
# Issue Backlog Index

The canonical local discovery backlog is [github-issues.md](github-issues.md): `CINE-001`–`CINE-006`. These are proposed local IDs only, not issues published to GitHub.

Implementation issue decomposition is intentionally deferred until CINE-006's architecture package is reconciled and approved. The kickoff's proposed milestone sequence M0–M13 is maintained in [roadmap.md](roadmap.md); issue owners and GitHub links remain unset.

## Completion evidence standard

An issue is done only when all acceptance criteria are demonstrated, responsible owners review changes, actual test commands/results are attached where tests apply, security/privacy/operational implications are addressed, docs/status are updated, no placeholder success or undocumented assumption remains, and dependent owners accept the interface. Security-sensitive work requires independent Critical Engineer review. Documentation-only issues require source links, assumptions, gaps, and owner review rather than fabricated test evidence.

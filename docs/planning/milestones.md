# Milestones

The kickoff defines M0–M13. Preserve these IDs and names exactly. They are local proposed milestones, not GitHub milestones until Product and Architect establish scope and publish them. Current architecture and quality packages are drafts awaiting approval; no code or tests exist.

| ID | Name | Entry criteria/status |
|---|---|---|
| M0 | Project Initialization | Active; shared docs drafted; Director review and repo/issue workflow required |
| M1 | Architecture and Engineering Foundation | Active; architecture/research/quality drafts exist; Architect + Director approval pending |
| M2 | Backend and Database Foundation | Blocked on M1 contracts and approved stack |
| M3 | Authentication and Profiles | Blocked on M1 identity/security decisions |
| M4 | Movie Catalog | Blocked on M1 model/contracts and source terms |
| M5 | Content Ingestion and Licensing | Blocked on rights model, territories and legal review |
| M6 | Search and Discovery | Blocked on product journeys, catalog contract and search decision |
| M7 | Media Processing | Processing approach is conditional on whether CINEFLOW hosts/transcodes or uses an authorized external source; blocked on contracts |
| M8 | Video Playback | Eventual product commitment; MVP sequence and delivery model blocked on rights, target devices and provider/hosting decisions |
| M9 | Watchlists and History | Blocked on identity/profile and retention decisions |
| M10 | Recommendations | Eventual capability; ranking, personalization, privacy details and sequencing await approval |
| M11 | Admin Dashboard | Blocked on operator roles, rights workflow and audit contracts |
| M12 | Security and Performance | Requires implementable system, approved targets, independent verification |
| M13 | Production Deployment | Requires provider, operational owner and release/recovery evidence |

No milestone is complete. Do not infer dates. Each milestone needs an owner and explicit completion evidence. Keep M13 in the roadmap; its execution is conditional on all launch gates, not removed or renumbered.
